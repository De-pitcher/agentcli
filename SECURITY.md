# Security Policy

## Supported Versions

Currently only the latest version of `agentcli` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability. 

Instead, report it by emailing security@example.com. We will respond within 48 hours to acknowledge the report and provide an estimated timeline for the fix and disclosure.
